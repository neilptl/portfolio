Featured work · Technical resource

ML Algorithm Framework

Machine learning: choose by purpose

Download the guide ↓
Quick-reference guide

A concise comparison of methods across tabular data, computer vision, natural language processing, and generative AI. Start with the source of the training signal, not just the name of the model.

Open the original PDF ↗

Introduction

Choosing a machine learning approach begins with understanding what a method learns, how it learns, and the problem it is intended to address. This framework organizes those distinctions into a single-page reference.

Description

The guide compares 12 algorithm and model families. Each entry identifies a training setup, explains how the method works, gives an illustrative use case, and highlights an important distinction or limitation.

Objective

Provide a starting point for comparing supervised, unsupervised, and self-supervised approaches while distinguishing learning style from application domain.

Process

I reviewed learning materials and used them as the foundation for a concise comparison of machine learning methods. I organized the concepts by learning signal, summarized how each method works, and included illustrative applications and key distinctions. I used Canva to arrange this information into a single-page visual framework, making it easier to scan and compare the methods.

Tools and technologies used

Authoring tool: Canva, used to design and lay out the framework. Learning resources: study materials, with scikit-learn and PyTorch documentation and foundational research papers cited in the guide. Deliverable: a shareable PDF quick-reference guide.

Technical topics: regression, tree ensembles, support vector machines, CNNs, clustering, PCA, transformers, GANs, and diffusion models. This artifact is a conceptual comparison guide; it does not involve software implementation or model training.

Value proposition

Gives learners a compact resource for discussing model choices, recognizing baseline approaches, and connecting machine learning concepts to practical tasks before investigating implementation details.

Unique value

Combines learning-signal classification, mechanisms, use cases, and model-family relationships in one place. It explicitly distinguishes random forests from boosting and BERT-style understanding from GPT-style generation.

Relevance

Designed for anyone seeking an approachable starting point for comparing machine learning methods. The examples connect methods to pricing, churn, fraud, manufacturing inspection, customer segmentation, text analysis, and content generation.
